# 🚴 Sales Analysis Dashboard

Interactive Power BI dashboard showcasing Adventure Works sales insights through data cleaning, modeling, and visualization.

---

# 📌 Project Overview

This project analyzes Adventure Works sales data using Microsoft Power BI.  
It includes data cleaning, transformation, data modeling, DAX calculations, and interactive dashboard creation to generate meaningful business insights.

The dashboard helps analyze:
- Sales performance
- Product profitability
- Customer behavior
- Regional sales trends
- Return analysis
- KPI tracking

---

# 🛠 Tools & Skills Used

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Interactive Dashboard Design
- Business Intelligence & Visualization

---

# 🔑 Key Insights

- United States generated the highest revenue among all countries.
- Accessories category recorded the highest number of orders.
- Revenue peaked during 2021 sales performance.
- Higher-income customers contributed the largest revenue share.
- Mountain-200 product series emerged as the top-performing product line.
- Return rates remained low across major products and categories.
